# Игры для Линки

Фанатские мини-игры про стримершу Линку (smilelinka) и корги Зевса. Сделано зрителем в подарок.

- [Линка на рыбалке](https://ar4ebald.github.io/linka-games/rybalka/) — ночная рыбалка на стриме.
- [Доктор Алинка](https://ar4ebald.github.io/linka-games/doctor-alinka/) — реалистичный стоматолог. Картинки, видео и голос сделаны нейросетью Grok, с согласия Линки.
